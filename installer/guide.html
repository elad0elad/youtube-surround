YouTube Surround מותקן

הרכיב של Windows כבר מוכן. נשאר לחבר את התוסף בדפדפן, פעם אחת. אותו הסבר באנגלית נמצא למטה.

חיבור התוסף

  1. 1. בדף התוספים שנפתח, הפעילו Developer mode (מצב מפתח) בפינה הימנית העליונה. ב־Brave זה brave://extensions. ב־Chrome זה chrome://extensions.
  2. 2. לחצו Load unpacked (טעינה ללא אריזה).
  3. 3. בחרו את התיקייה הזו, לא קובץ שבתוכה. חלון של התיקייה נפתח כדי שאפשר יהיה לסמן אותה. __EXT_PATH__
  4. 4. ודאו ש־YouTube Surround מופיע ברשימה ושהמתג שלו דולק. בתיאור כתוב elad0elad. בחלון של התוסף, בתחתית, מופיע © 2026 elad0elad.
  5. 5. פתחו סרטון ב־YouTube. סרטון שנבדק עם מקור IAMF אמיתי: youtube.com/watch?v=iMrnS6finbA. אחרי כמה שניות מופיע על הנגן 5.1 Active.

מה אמור לקרות

הדפדפן ממשיך להציג את התמונה. ששת ערוצי השמע יוצאים מתוכנית Windows נפרדת, מסונכרנים לשעון של הסרטון. בזמן ש־5.1 באמת מתנגן, הסטריאו של YouTube עצמו שקט, כדי שלא ישמעו שני מקורות יחד.

  • 5.1 Active — נמצא מקור IAMF, הוא פוענח לשישה ערוצים, והם מתנגנים.
  • Stereo source — לסרטון הזה אין מקור סראונד. נשאר הסטריאו המקורי. זו תוצאה תקינה, לא תקלה.
  • Surround unavailable — Windows לא מוגדר ליציאת 5.1. הסרטון נשאר בסטריאו.

איך משתמשים

לוחצים על סמל התוסף ליד שורת הכתובת.

  • Automatic בודק כל סרטון לבד. בלי מקור סראונד נשאר סטריאו.
  • Manual מחכה ללחיצה על Play Surround. Stereo מחזיר את השמע של YouTube.
  • כפתור ההשתקה והמחוון של הנגן ביוטיוב שולטים גם בעוצמה של ה־5.1. הגברה בדפדפן מגבירה, הנמכה מנמיכה, והשתקה משתיקה.
  • Test speakers משמיע צליל אחר בכל רמקול: קדמי שמאל 220 הרץ, קדמי ימין 277, מרכז 330, סאב 55, סראונד שמאל 440, סראונד ימין 554. כל צליל צריך לצאת מרמקול אחד בלבד.

מה צריך בשמע

Windows צריך להיות מוגדר לרמקולים ב־5.1, לא לאוזניות ולא ליציאת סטריאו. סדר החיבור: קדמי שמאל, קדמי ימין, מרכז, סאב, סראונד שמאל, סראונד ימין. אם ברירת המחדל היא סטריאו, התוסף משאיר את השמע של YouTube ולא ממציא 5.1.

אם זה לא מתנגן

  • רעננו את הלשונית של YouTube אחרי טעינת התוסף.
  • בדקו ש־Windows מנגן דרך רמקולי ה־5.1.
  • הריצו Test speakers. אם צליל יוצא מהרמקול הלא נכון, סדר החיבור ב־Windows לא תואם.
  • אם מופיעה הודעה שהרכיב של Windows חסר, הריצו שוב את קובץ ההתקנה.
  • יומן: %LOCALAPPDATA%\YouTubeSurround\host.log

הסרה

בדף התוספים הסירו את YouTube Surround. למחיקת הרכיב של Windows הריצו uninstall.cmd מתוך חבילת ההתקנה.

YouTube Surround is installed

The Windows component is ready. One browser step remains, and it is done only once. The same guide in Hebrew is above.

Turn the extension on

  1. 1. On the extensions page that opened, switch on Developer mode in the top-right corner. Brave uses brave://extensions. Chrome uses chrome://extensions.
  2. 2. Click Load unpacked.
  3. 3. Select this folder. Do not open it and pick a file inside. A window for the folder was opened so it can be selected. __EXT_PATH__
  4. 4. Confirm that YouTube Surround is in the list and that its switch is on. The description includes elad0elad. The extension popup shows © 2026 elad0elad at the bottom.
  5. 5. Open a YouTube video. One video that was checked with a real IAMF source is youtube.com/watch?v=iMrnS6finbA. After a few seconds the player shows 5.1 Active.

What should happen

The browser keeps showing the picture. The six audio channels come from a separate Windows program and follow the video clock. While 5.1 is actually playing, YouTube's own stereo is silent, so the two sources are not heard together.

  • 5.1 Active — an IAMF source was found, decoded to six channels, and is playing.
  • Stereo source — this video has no surround source. Original stereo keeps playing. That is the correct result.
  • Surround unavailable — Windows is not using a 5.1 output. The video stays stereo.

How to use it

Click the extension icon next to the address bar.

  • Automatic checks every video. Without a surround source, playback stays stereo.
  • Manual waits for Play Surround. Stereo returns YouTube's own audio.
  • YouTube's mute button and volume slider also control the 5.1 program. Raising the slider raises it, lowering the slider lowers it, and mute silences it.
  • Test speakers plays a different tone on each speaker: front left 220 Hz, front right 277 Hz, center 330 Hz, LFE 55 Hz, surround left 440 Hz, surround right 554 Hz. Each tone should come from one speaker only.

Sound setup

Windows must be set to 5.1 speakers, not headphones and not a stereo output. Wiring order: front left, front right, center, subwoofer, surround left, surround right. If the default device is stereo, the extension leaves YouTube's audio alone and does not invent 5.1.

If nothing plays in surround

  • Reload the YouTube tab after loading the extension.
  • Confirm Windows is using the 5.1 speakers.
  • Run Test speakers. A tone from the wrong speaker means the Windows speaker order does not match the wiring.
  • If the badge says the Windows component is missing, run the setup file again.
  • Log file: %LOCALAPPDATA%\YouTubeSurround\host.log

Remove

On the extensions page, remove YouTube Surround. To delete the Windows component, run uninstall.cmd from the setup package.
