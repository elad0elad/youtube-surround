YouTube Surround מותקן

הרכיב של Windows כבר מוכן. נשאר לחבר את התוסף בדפדפן, פעם אחת. אותו הסבר באנגלית נמצא למטה.

חיבור התוסף

  1. 1. בדף התוספים שנפתח, הפעילו Developer mode (מצב מפתח) בפינה הימנית העליונה. ב־Brave זה brave://extensions. ב־Chrome זה chrome://extensions.
  2. 2. לחצו Load unpacked (טעינה ללא אריזה).
  3. 3. בחרו את התיקייה הזו, לא קובץ שבתוכה. חלון של התיקייה נפתח כדי שאפשר יהיה לסמן אותה. __EXT_PATH__
  4. 4. ודאו ש־YouTube Surround מופיע ברשימה ושהמתג שלו דולק. בתיאור כתוב elad0elad. בחלון של התוסף, בתחתית, מופיע © 2026 elad0elad.
  5. 5. פתחו סרטון ב־YouTube. סרטון שנבדק עם מקור IAMF אמיתי: youtube.com/watch?v=iMrnS6finbA. אחרי כמה שניות מופיע על הנגן 5.1 Active.

מה אמור לקרות

הדפדפן ממשיך להציג את התמונה. השמע מתחיל אחרי השניות הראשונות, והמשך של סרטון ארוך ממשיך לרדת בזמן הצפייה. בזמן שהנגן החיצוני באמת מנגן, הסטריאו של YouTube עצמו שקט. אם קופצים למקום שעוד לא ירד, נשמע בינתיים הסטריאו הרגיל.

  • 5.1 Active — נמצא מקור IAMF, והוא מתנגן כשישה ערוצים נפרדים.
  • Dolby Atmos — שישה הערוצים מתנגנים דרך Dolby Atmos for Headphones כשזה הפורמט שנבחר ב־Windows.
  • Stereo downmix — השישה ערוצים מקופלים לסטריאו, כולל המרכז, הסראונד והסאב.
  • Stereo source — לסרטון הזה אין מקור סראונד. נשאר הסטריאו המקורי.

איך משתמשים

לוחצים על סמל התוסף ליד שורת הכתובת.

  • Automatic בודק כל סרטון לבד. בלי מקור סראונד נשאר סטריאו.
  • Manual מחכה ללחיצה על Play Surround. Stereo מחזיר את השמע של YouTube.
  • תפריט הפלט: Auto Detect, 5.1 Speakers, Dolby Atmos Headphones, Surround Headphones, Stereo Headphones. הבחירה נשמרת. מתחתיה מופיעים המצב שבאמת פעיל ושם ההתקן.
  • חיבור אוזניות או רמקולים בזמן שהסרטון מתנגן מעביר את הפלט להתקן החדש. השם שלו מופיע על הנגן ובחלון התוסף.
  • כפתור ההשתקה והמחוון של הנגן ביוטיוב שולטים גם בעוצמה של הנגן החיצוני.
  • Test Audio משמיע צליל אחר בכל ערוץ: קדמי שמאל 220 הרץ, קדמי ימין 277, מרכז 330, סאב 55, סראונד שמאל 440, סראונד ימין 554.

מה צריך בשמע

5.1 ישיר דורש שהתקן הפלט של Windows כבר יהיה בשישה ערוצים. סדר החיבור: קדמי שמאל, קדמי ימין, מרכז, סאב, סראונד שמאל, סראונד ימין. באוזניות Xbox ובכל אוזניות ש־Windows שלהן מוגדר ל־Dolby Atmos for Headphones, המיקס של 5.1 נשאר על Dolby ולא עובר לדאוןמיקס. אם Dolby לא פעיל, מתנגן דאוןמיקס ומופיעה הודעה.

אם זה לא מתנגן

  • רעננו את הלשונית של YouTube אחרי טעינת התוסף.
  • לרמקולים, בחרו 5.1 Speakers וודאו ש־Windows מנגן דרך יציאת שישה ערוצים.
  • הריצו Test Audio. אם צליל יוצא מהרמקול הלא נכון, סדר החיבור ב־Windows לא תואם.
  • אם מופיעה הודעה שהרכיב של Windows חסר, הריצו שוב את קובץ ההתקנה.
  • יומן: %LOCALAPPDATA%\YouTubeSurround\host.log

הסרה

בדף התוספים הסירו את YouTube Surround. למחיקת הרכיב של Windows הריצו uninstall.cmd מתוך חבילת ההתקנה.

YouTube Surround is installed

The Windows component is ready. One browser step remains, and it is done only once. The same guide in Hebrew is above.

Turn the extension on

  1. 1. On the extensions page that opened, switch on Developer mode in the top-right corner. Brave uses brave://extensions. Chrome uses chrome://extensions.
  2. 2. Click Load unpacked.
  3. 3. Select this folder. Do not open it and pick a file inside. A window for the folder was opened so it can be selected. __EXT_PATH__
  4. 4. Confirm that YouTube Surround is in the list and that its switch is on. The description includes elad0elad. The extension popup shows © 2026 elad0elad at the bottom.
  5. 5. Open a YouTube video. One video that was checked with a real IAMF source is youtube.com/watch?v=iMrnS6finbA. After a few seconds the player shows 5.1 Active.

What should happen

The browser keeps showing the picture. Sound starts after the first seconds, and the rest of a long video keeps downloading while it plays. While the external player is actually playing, YouTube's own stereo is silent. Seeking past the part that has downloaded plays the original stereo until playback catches up.

  • 5.1 Active — an IAMF source was found and is playing as six separate channels.
  • Dolby Atmos — the six channels play through Dolby Atmos for Headphones when that is the format selected in Windows.
  • Stereo downmix — the six channels are folded to stereo, including center, surrounds, and LFE.
  • Stereo source — this video has no surround source. Original stereo keeps playing.

How to use it

Click the extension icon next to the address bar.

  • Automatic checks every video. Without a surround source, playback stays stereo.
  • Manual waits for Play Surround. Stereo returns YouTube's own audio.
  • The output menu has Auto Detect, 5.1 Speakers, Dolby Atmos Headphones, Surround Headphones, and Stereo Headphones. The choice is saved. Under it, the popup shows the route that is actually active and the device name.
  • Connecting headphones or speakers while a video is playing switches the output to that device. Its name appears on the player and in the popup.
  • YouTube's mute button and volume slider also control the external player.
  • Test Audio plays a different tone on each channel: front left 220 Hz, front right 277 Hz, center 330 Hz, LFE 55 Hz, surround left 440 Hz, surround right 554 Hz.

Sound setup

Direct 5.1 needs a Windows output whose shared format is already six channels. Wiring order: front left, front right, center, subwoofer, surround left, surround right. On an Xbox headset, and on any headphones whose Windows format is Dolby Atmos for Headphones, the 5.1 mix stays on Dolby and does not fall back to a downmix. If Dolby is not active, playback uses the stereo downmix and the popup says so.

If nothing plays in surround

  • Reload the YouTube tab after loading the extension.
  • For speakers, choose 5.1 Speakers and confirm Windows is using a six-channel output.
  • Run Test Audio. A tone from the wrong speaker means the Windows speaker order does not match the wiring.
  • If the badge says the Windows component is missing, run the setup file again.
  • Log file: %LOCALAPPDATA%\YouTubeSurround\host.log

Remove

On the extensions page, remove YouTube Surround. To delete the Windows component, run uninstall.cmd from the setup package.
